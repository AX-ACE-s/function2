# 우리동네 대형폐기물 수수료 — 기능 ② 지역 기준 맞춤 규격 질문 · 실측 보정

품목과 배출 지역을 고르면, **그 지자체 수수료표에 실제로 있는 규격 기준만** 질문하고,
실측값(cm·L·kg 등)을 공식 규격 구간에 맞춰 예상 수수료와 산정 근거를 보여 주는 웹서비스.

```
STEP 1 지역·품목 → STEP 2 규격 질문 → STEP 3 입력 확인(실측 보정) → STEP 4 예상 수수료 + 근거·출처
```

## 빠른 실행

```bash
pip install -r requirements.txt
cp .env.example .env            # 주소검색 키가 있으면 JUSO_API_KEY 입력 (없어도 동작)
python -m etl.build_db          # data/raw/*.csv → data/processed/fees.db
python -m etl.analyze           # reports/analysis.md + CSV 생성
uvicorn app.main:app --reload   # http://127.0.0.1:8000
pytest -q                       # 68개 테스트 (전체 원본 23,186행 금액 일치 검증 포함)
```

## 엔진 동작 (app/services/engine.py)

서버에 세션을 저장하지 않는다. 화면이 지금까지의 답을 보내면 **다음 질문 1개** 또는 **결과**를 돌려준다.

| 순서 | 조건 | 질문 |
|---|---|---|
| 1 | 한 표준 품목에 지역 품목이 여럿 (부여군 장식장/진열장) | 어느 품목인지 선택 |
| 2 | 규격에 종류 구분이 있음 (해운대구 매트리스 라텍스/일반형) | 종류 선택 |
| 3 | 남은 규격이 같은 수치 기준을 공유 (가로·높이·L·kg·인용·단) | **실측값 입력** + 모르면 공식 규격 선택 |
| 4 | 수치로 해석 못 하는 규격 (그랜드/업라이트) | 공식 규격 선택 |
| 5 | 단위당 요금 (1㎡당, 100L당) | 수량 입력 → 단위 수 올림 |

- **설명 읽기**: "폭 180cm 3인용 소파", "450리터 냉장고", "18평형 에어컨 2개"처럼 쓰면 품목·치수·수량을 읽어 해당 질문을 건너뛴다(`app/services/describe.py`). 단위가 적힌 숫자만 읽고, "180cm"처럼 방향이 없는 길이는 자동 적용하지 않고 입력칸에 미리 넣어 확인받는다. 직접 입력한 값이 설명보다 우선한다.
- **②→③ 인계**: 규격이 확정되면 결과에 `handoff`(지역·품목·확정 규격 번호·수량)를 담는다. `docs/HANDOFF.md` 참고.
- **실측 보정**: 공식 규격을 직접 골랐는데 나중에 넣은 실측값이 그 규격 범위를 벗어나면, 맞는 규격과 금액을 제안한다.
- **입력 검증**: 숫자 아님, 0 이하, 허용 범위 밖이면 다시 묻는다. 1.3cm처럼 m로 착각한 값은 "1.3m = 130cm"로 안내.
- **임의 계산 금지**: 실측값이 어떤 구간에도 안 들어가면 금액을 만들지 않고 공식 규격 선택으로 돌린다. 같은 규격에 수수료가 2개 등록된 충돌 데이터는 `needs_confirmation`으로 두 금액을 모두 보여 주고 지자체 확인을 안내한다.
- **구간 중첩 규칙**: '2인용 150cm 이하 / 3인용 151cm 이하'처럼 겹치면 포함관계상 가장 좁은 구간을 적용하고, 그 규칙을 결과 근거에 적는다.

## 환경변수 (.env)

| 변수 | 필수 | 설명 |
|---|---|---|
| `JUSO_API_KEY` | 선택 | 공공데이터포털 15057017 / business.juso.go.kr 승인키. 없으면 주소검색만 꺼지고 시·도/시·군·구 선택으로 동작 |
| `JUSO_API_URL` | 선택 | 기본 `https://business.juso.go.kr/addrlink/addrLinkApi.do` |
| `FEE_DB_PATH` | 선택 | 기본 `data/processed/fees.db` |

키는 `.env`에만 두고 커밋하지 않는다(`.gitignore` 포함).

승인키가 `=`로 끝나도 그대로 붙여 넣으면 된다. `.env`는 첫 번째 `=`만 기준으로 나누고, 서버가 API를 부를 때 자동으로 URL 인코딩한다.

```
JUSO_API_KEY="발급받은키그대로=="
```

브라우저 주소창에서 직접 시험할 때만 끝의 `=`를 `%3D`로 바꿔 넣는다.
